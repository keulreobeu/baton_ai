## META-MAP-001-REQ-01 기존 계약과 Spec Kit 보기의 동등성

### META-MAP-001-AC-01

등록된 모든 문서·레지스트리 원문과 REQ→AC→테스트·Task 관계를 보존한다. 각 feature의 spec.md·plan.md·tasks.md는 같은 원본에서 생성한다. 공유 계획·Task도 해당하는 모든 feature에 나타나야 한다.

오프라인 재검사에서 누락, ID/승인/상태/증거/후보 변경 및 표시 내용의 불일치를 거부한다. 두 판독 경로에서 기존 fixture의 판정과 실패 코드를 보존한다. 작업 중단 후 원본으로 다시 생성할 수 있다.
