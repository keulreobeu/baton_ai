# 토큰 소비 기준선 — 처음부터 / 같은 세션 재개 / 다른 세션 재개

기록일 2026-11-04 (KST). 측정 대상: BATON 복사·P0·SDD 도입 작업.
**실측**은 로컬 세션 로그(`~/.claude/projects/.../*.jsonl`, `~/.codex/sessions/**/*.jsonl`)와
앱의 사용량 표시에서 읽은 값이다. **추정**은 실측에서 계산한 값이고, 아직 실험으로 확인하지 않았다.

## 읽는 법

- 토큰 수와 한도 소모는 비례하지 않는다. 캐시 읽기는 싸고, 캐시 쓰기는 비싸며, 가중치는 공개되어 있지 않다. 그래서 토큰과 한도 %p를 함께 적는다.
- Claude와 Codex의 토큰·%는 서로 환산하지 않는다. 플랜과 모델이 다르다.
- 호출 비용은 대체로 그 시점의 컨텍스트 크기에 비례한다. 재개 방식의 차이는 대부분 여기서 나온다.

## 추정 — 다음 Task 1건(호출 60회 가정)의 소비

호출 60회는 가정이다. 평균 컨텍스트는 재개 지점 크기와 작업 중 증가분으로 잡았다.

| 방식 | 시작 비용 | 평균 컨텍스트 | 누적 처리 토큰 | Claude 5시간 한도 |
|---|---|---:|---:|---|
| A. Claude 같은 세션, 캐시 살아 있음 | 없음 | 약 72만 | 약 4,300만 | 약 26%p |
| B. Claude 같은 세션, 1시간 넘게 쉼 | 캐시 쓰기 약 70만 | 약 72만 | 약 4,400만 | 약 35~40%p |
| C. Claude 새 세션 + HANDOFF | 약 10만 | 약 17만 | 약 1,000만 | 약 6~10%p |
| D. Codex 같은 스레드 | 33만, 캐시 적중 불확실 | 약 35만 | 약 2,100만 | 해당 없음 |
| E. Codex 새 스레드 + HANDOFF | 약 5~10만 | 약 15만 | 약 900만 | 해당 없음 |
| F. 처음부터 전부 다시 | 없음 | — | 약 1억 (실측 1 합계) | 5시간 창 1개 이상 + Codex 창 절반 |

해석: 큰 세션을 이어 쓰는 것은 문맥을 그대로 쓸 수 있지만 호출마다 비싸다. 새 세션은 인계 문서를 읽는 비용과 문맥 손실 위험이 있지만 호출이 훨씬 싸다.
재작업이 늘면 이 차이가 줄어들 수 있으므로, 품질까지 같이 기록해야 결론을 낼 수 있다.
