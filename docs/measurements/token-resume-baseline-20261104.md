## 고정 기준선과 절감 추정

같은 작업을 두 번 하지 않고, 실제 호출 수는 그대로 둔 채 컨텍스트만 기준값으로 바꿔 계산한다.
결과는 측정값이 아니라 추정치로 표시한다. 기준값은 바꾸지 않는다.

```text
기존 방식 예상 = 실제 호출 수 × 기준 컨텍스트 + 재개 비용
절감률        = 1 − (실제 처리 토큰 ÷ 기존 방식 예상)
```

| 2026-11-04 기준값 | 값 |
|---|---:|
| Claude 큰 세션 컨텍스트 | 680,000 / 호출 |
| Claude 캐시 만료 재개 비용 | 605,077 (캐시 쓰기) |
| Claude 새 세션 참고값 | 170,000 / 호출 (추정) |
| Codex 큰 스레드 컨텍스트 | 330,000 / 호출 |

함께 볼 값: 실제 호출 수, 재작업 횟수, 닫힌 게이트 또는 검증 AC 1개당 토큰, 구독 한도 %p.
Claude와 Codex는 합치지 않는다. 한 건이 아니라 여러 건의 평균과 범위로 판단한다.

### 비교 단위와 해석

- `N`은 해당 구간의 실제 메인 호출 수다. 하위 에이전트/다른 채팅은 별도 집계한다.
- Claude 실제 처리량 = 입력 + 캐시 쓰기 + 캐시 읽기 + 출력.
- Codex 실제 처리량 = `total_tokens` = 입력 + 출력. 캐시 입력은 입력에, 추론 출력은 출력에 이미 포함된다.
- 문서 미사용 예상은 **큰 기존 세션을 계속 사용하는 가정**이다. 문서 없이 새 채팅에서 재탐색하는 비용은 unknown이다.
- 예상 처리량 = `N × 기존 고정 컨텍스트 + 실제 출력`. 출력은 양쪽에 동일하게 넣는다.
  이번 두 비교는 캐시 유지/재개 추가 비용 0 가정이다. Claude 캐시 만료 가정은 605,077을 별도 더하고 실제값에 더하지 않는다.
- 차이율 = `1 - 실제 처리량 / 예상 처리량`. 요금·구독 한도 절감률이나 문서만의 인과 효과가 아니다.
  같은 세션에서 문서를 읽어도 누적 대화는 줄어들지 않으며, 미사용 대조군을 실행하지 않았다.
