2026-11-26 사용자의 최종 설계 §12~23, 27 및 구현 착수 지시를 적용한다. 프로젝트가 선택한 운영 방식은 기존 정본 한 곳에서 읽고, 기기별 경로·설치·활성·검증은 그 환경에서 관측한다. 새 권한·비용·설치·주요 기능은 구체적 사용 목적과 대상에 묶는다. 프로젝트 지침과 에이전트가 집행하고 현행 권한 요청·배정·검증·Git 보호 수단을 재사용한다.

## Eng Review Amendments

- 초기 4프로필·일괄 roadmap off 초안은 §19의 프리셋으로 교체한다. 기존 사용자의 명시적 off는 이전 전까지 보존한다. Full 계약을 확인할 수 없으면 미구성으로 둔다.
- 선택과 실행 증거를 분리한다. 실제로 로드되지 않은 스킬, Orca가 발견하지 못한 공급자, 다른 후보의 리뷰를 성공으로 계산하지 않는다. 사용자 편집 파일의 충돌이 전체 Setup을 재초기화하지 않도록 해당 쓰기만 보류한다.
- checkout 없이도 wheel로 전달할 수 있게 같은 상대 경로의 두 Markdown을 포함한다. 기존 data-files와 wheel qualification에서 확인한다.
